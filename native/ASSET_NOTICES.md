# Adzuna attribution image

`adzuna-logo.png` is the official attribution image from
https://developer.adzuna.com/images/adzuna_logo.png, verified on 2026-10-05.
The downloaded image and the committed image have the same SHA-256:
`8c9922fed56c285a1879be628c285f311164ca1af299a4ae95927c2c7ec7a8af`.

Adzuna's API terms require the linked “Jobs by Adzuna” label, including the
Adzuna logo, on displayed Adzuna listings:
https://developer.adzuna.com/docs/terms_of_service.
Stack uses this image only for that attribution. It is an Adzuna brand asset,
not Stack artwork or an asset offered under Stack's source-code license.
Retain the attribution when displaying Adzuna listings; the whole label is
linked to Adzuna and has a minimum size of 116 × 23 pixels.

This attribution requirement does not grant permission to redistribute
employer vacancy text as a reusable test dataset. Stack's matching fixtures
contain original synthetic descriptions instead.
